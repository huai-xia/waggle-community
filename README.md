# Waggle Community

公开的 **Issue / Star** 入口。产品源码在私人仓库，这里不开放源码 PR。

**职巢 Waggle**：岗位信息一起采，投递进度各自留。

## 你可以在这里做什么

| 可以 | 不可以 |
|:--|:--|
| 开 **Issue**（bug、建议、许愿） | 提 **源码 Pull Request**（看不到代码，合不进去） |
| **Star** 表示关注 | 期望这里出现完整源码 |

已登录产品的用户：优先用站内「反馈」（更方便带页面与截图）。路人或想公开讨论，用本仓 Issue。

## 开 Issue 之前

1. 搜一下有没有类似 Issue  
2. 写清：现象 / 期望 / 复现步骤（有网址或截图更好）  
3. 不要贴简历、密码、内推隐私等个人敏感信息  

## 源码与贡献

代码仓是私人的。社区 Issue 会由维护者同步到内部跟踪；值得做的改动由维护者在私仓实现。  
若你只想改本仓的说明文档，可以开 Issue 说明要改哪里，我们代为更新。

## 相关

- 产品：由维护者另行公布访问地址  
- 本仓只作社区入口，不部署服务
